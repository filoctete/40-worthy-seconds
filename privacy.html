Privacy policy — Painel Stickman

Last updated: 18 November 2026

Painel Stickman is a personal tool run by the owner of the "40 worthy seconds" channel on their own computer. Only the owner uses it.

What it accesses

With the owner's permission through Google sign-in, it uploads videos to the owner's YouTube channel, schedules them, and uploads the video files to the owner's Google Drive.

What it stores

The sign-in tokens are kept only in a local file on the owner's computer. The tool has no server, database or analytics, and it collects no data about anyone else.

Sharing

No data is sold or shared with third parties. Google user data is used only to upload and schedule the owner's own videos, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local file removes all stored tokens.
